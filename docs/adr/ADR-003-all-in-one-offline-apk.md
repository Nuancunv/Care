# ADR-003：采用全量离线一体 APK 分发策略

- **状态**：已确认（Accepted）
- **决策日期**：2026-11-25
- **相关模块**：`runtime/`、`app/android/`、`scripts/`

## 背景

本机运行 DeepSeek Harness (`dsh`) 需要内置 PRoot、精简 Ubuntu rootfs、Node.js（`arm64-v8a`）、`dsh` 引擎与 `care-bot` 插件。分发存在两种方案：
- 方案 A：精简 APK + 首启从远程服务器/镜像下载运行时压缩包；
- 方案 B：全量离线一体 APK（将精简后的运行时资产直接内置于 APK `assets/` 或 `jniLibs/` 中，安装后本机解压即用）。

## 决策

1. **采用全量离线一体 APK（仅聚焦 `arm64-v8a`）**。
2. **零首启外网下载依赖**：除用户主动调用 DeepSeek API 推理外，App 安装与本地引擎初始化全程可完全离线完成，彻底贯彻“零官方云中转、零官方分发服务器依赖”的设计哲学。
3. **体积极致裁剪要求**：
   - 仅打包 `arm64-v8a` 单一 ABI；
   - 彻底剔除 `DS-Bot` 中的 `playwright-core` 及所有桌面依赖；
   - 精简 PRoot Ubuntu rootfs，仅保留运行 Node.js + `dsh` + `care-bot` 必需的最小用户态库；
   - 运行时资产采用高压缩比归档（如 `.tar.zst` / `.tar.xz`），首启时在本机异步解压至 App 私有目录并展示清晰进度。

## 影响

- **正面**：彻底摆脱对官方 CDN/镜像服务器的依赖，国内弱网或离线环境下首启成功率 100%，隐私感与离线可控性极强。
- **约束**：单个 APK 体积较大（目标控制在精简后合理区间，持续监控每版体积变化）；开发阶段需在 **OPPO Find X8s+（ColorOS / arm64-v8a）** 上实测安装耗时、首次解压耗时与存储占用。
