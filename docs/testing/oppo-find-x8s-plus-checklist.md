# Care v0.1.0-beta — OPPO Find X8s+（ColorOS）真机验收清单

> **目标机型**：OPPO Find X8s+（`arm64-v8a`，ColorOS）  
> **测试包体**：`app/build/app/outputs/flutter-apk/app-arm64-release.apk`（或 `app-arm64-debug.apk`）

---

## 1. 安装与首启 BYOK 直连（M1）
- [ ] **离线安装**：通过 USB/本地文件直接安装 APK，ColorOS 安全校验正常通过，图标与名称显示为 **Care**。
- [ ] **首启引导**：展示青玉绿暖调欢迎页 → 粘贴 DeepSeek API Key → 点击「保存并测试连接」→ 提示连接正常并进入主对话页。
- [ ] **零语音与去极客化核验**：主界面无麦克风/语音入口（ADR-002）；主界面、今日、设置首页不出现 `PRoot` / `Cordis` / `Loopback` 等工程术语。
- [ ] **流式对话与深度思考**：发送常规问题流畅逐字输出；切换输入栏「深度思考」芯片发送推理题，可展开/折叠思考过程并流畅无卡顿。
- [ ] **外观切换**：在「设置 → 外观」切换浅色 / 深色 / 跟随系统，重启 App 后保持生效。

## 2. 透明人格、主动关怀与本机生态（M1 + M2）
- [ ] **记忆与性格中心**：进入右上角「记忆与性格」，分别编辑 `MEMORY.md` 与 `SOUL.md` 并保存；重启后内容完整保留，且对话回复体现新偏好。
- [ ] **早晚简报与提醒**：进入「今日」点击「早间简报」/「晚间回顾」生成本地简报；点击「聊聊这份简报」直接带入主对话；添加一条 2 分钟后提醒并验证系统通知与「完成 / 推迟 15 分钟」快捷按钮。
- [ ] **系统日历与白名单通知**：按需授权日历后显示近 7 天日程并可新建日程；在「主动关怀 → 通知摘要」勾选常用快递/出行应用芯片，验证普通通知被采集、验证码/OTP 短信被原生过滤。
- [ ] **ColorOS 后台省电**：在「设置 → 后台与耗电」点击「允许后台运行 → 去设置」，按 ColorOS 引导设为允许完全后台行为，验证提醒准时触达且无异常发热。

## 3. 手机自动化、原生安全门与例程（M3）
- [ ] **ColorOS 无障碍引导与自检**：进入「设置 → 手机自动化」，确认页面自动显示 ColorOS 无障碍开启路径提示；前往「系统设置 → 辅助功能 → 已下载的应用 → Care」开启后切回，页面自动刷新为「已开启 / 运行正常」。
- [ ] **脱敏界面读取与隐私硬拦截**：点击「测试读取」正常返回脱敏节点数；切到支付宝或系统设置时由原生策略直接硬拦截。
- [ ] **例程管理**：点击例程卡片展开查看步骤明细，运行内置例程验证执行反馈；测试全局紧急停止与恢复流程。

## 4. 多 Bot 团队、隐私空间与本地加密备份（M4）
- [ ] **孵化专职助手**：点击主对话页顶部「Care ▾」进入「助手团队与隐私空间」，一键孵化「行程规划师」并切换对话，确认对话线程独立、切回「Care」上下文完整。
- [ ] **生物识别隐私空间**：点击「验证并解锁隐私空间」触发 OPPO 指纹/面容/锁屏验证；编辑私密笔记并进入私密对话，确认不与公共 `MEMORY.md` 互通；点击「申请导出摘要」确认弹出不可滑掉的原生 `SafetyGate` 审批卡；切到后台再切回确认自动重新上锁。
- [ ] **本地 AES-256-GCM 加密备份**：进入「设置 → 本地加密备份与迁移」，设定 6 位以上口令生成加密备份并复制；修改记忆后粘贴加密备份与口令完成恢复，核验记忆与助手恢复完整，且备份密文解密后不含 API Key 与隐私空间内容。

- [ ] 联网对话期间仅直连 `https://api.deepseek.com`（或用户显式配置的自定义端点），零第三方云中转请求。
